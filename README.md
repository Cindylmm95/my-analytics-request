# MyAnalyticsRequest

MyAnalyticsRequest is a conversational analytics request definition assistant built with **IBM watsonx Assistant**.

Sara guides a user through the business problem, question, decision, audience, metrics, data considerations, timing and expected outcome. The assistant then generates a structured **Analytics Request Brief** with a recommended solution.

## Technologies

- IBM watsonx Assistant
- HTML
- CSS
- JavaScript
- GitHub Pages

## Publish with GitHub Pages

1. Create a public repository named `my-analytics-request`.
2. Upload `index.html`, `styles.css`, `README.md`, and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**.
6. Save and wait for the public URL.

The URL will look like:

`https://YOUR-USERNAME.github.io/my-analytics-request/`
