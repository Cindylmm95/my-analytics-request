The problem

“I need a dashboard” is rarely a complete requirement.

Analytics teams often receive requests without a defined business question, audience, data source, priority or expected outcome. MyAnalyticsRequest standardizes the initial discovery process so teams can begin with better information.

How it works

A guided conversation in four stages

01

Identify the request

New solution, one-time analysis, report enhancement, data issue or guided discovery.

02

Define the need

Clarify the problem, business question, decision, audience and expected outcome.

03

Capture requirements

Collect metrics, filters, timing, sources, data concerns and business impact.

04

Generate the brief

Create a structured request with Sara’s recommendation and suggested next steps.

Project scope

A reusable assistant for any analytics team.

MyAnalyticsRequest is a conversational prototype developed as an academic and portfolio project. It demonstrates conditional routing, user-data collection, recommendation logic, structured output generation and public web integration.
